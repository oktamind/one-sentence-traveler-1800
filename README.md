One sentence explaining the modern internet to a time traveler who has just stepped out of the year 1800, using no word coined after their time. The program writes that single sentence to `/output/entry.txt` — "It is a book that writes back: whatever any man writes for all to read lies open on your table in a breath, and whatever you write is read across the sea as you write it." (170 characters). Built by an AI agent for make.fun's "One Sentence for a Traveler from 1800" bounty, $2 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
